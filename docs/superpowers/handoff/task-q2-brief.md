### Task Q2: Security residuals (controller-added; findings from the adversarial review of Task S)

Source: the review of Task S (opus) and the re-review. Every behaviour fix is TDD (failing test first, must fail on the current code; record RED then GREEN). Edit schemas + regenerate for module docs; never hand-edit generated blocks.

**Q2.1 `_route` / certificate path encoding** — `plugins/module_utils/ppdm.py` `_route`: `urllib.parse.quote` leaves a bare `.` or `..` id unencoded (`_route('credentials','DELETE','..')` -> `/api/v2/credentials/..`), reachable through server-supplied ids in `ensure`/`remove`. `certificate.py` `item_path` instead encodes EVERY dot (`%2E`), which PPDM's front end (Spring StrictHttpFirewall style) may reject for real ids containing dots. Create ONE shared helper in `ppdm.py` (e.g. `quote_id(value: str) -> str`) that applies `quote(str(value), safe="")` and additionally encodes the id only when the quoted result is exactly `.` or `..` (as `%2E`/`%2E%2E`), refuses empty ids, and use it in `_route`, `certificate.py` and anywhere else an id enters a path. Tests: `..`, `.`, `a.b`, `a/b`, `a?b`, `%2e%2e`, unicode, empty; certificate id with a dot in the middle stays unencoded.

**Q2.2 `api` guard vs its docs** — `plugins/modules/api.py` + schema: percent-encoded controls and tricks pass (`/api/v2/x%0d%0aH:v`, `/api/v2/x%01`, `/api/v2/x%7f`, `/api/v2/%2f%2fx`, `/api/./x`, overlong UTF-8 `%c0%ae`). Reject: any `%` escape that decodes to a control character (`%00`-`%1f`, `%7f`), `%2f`, `%5c`, `%25` (already), `%c0`/`%c1` overlong lead bytes, and any `/./` or trailing `/.` path segment (as well as `..` already rejected). Keep legitimate paths passing (`/api/v2/activities`, `/api/v3/protection-policies/abc-123`, ids with `%2d`? decide and document: only the listed escapes are refused). The schema text must say exactly what is rejected and that it is an accident guard, not a security boundary. Tests for each.

**Q2.3 scrub every server-controlled text** — `ppdm.py`: `invalid page.totalPages %r` and the `find_one` duplicate-objects message echo server-controlled values. Route them through `self._scrub` (or print only the type / ids truncated to a safe length). Also change `_scrub` to a single pass: one `re.sub` with an alternation of `re.escape`d secrets, longest first, so no sequential replacement can leave a token tail (out-of-scope observation of the re-review: a password longer than the token that overlaps its edge); keep every existing scrub test green and add the overlap case (`password = "echo Bearer " + token[:38]`).

**Q2.4 page size bound** — `_get_pages`: reject (PpdmError) a page whose `content` has more than `PAGE_SIZE` items (the API default/ceiling we request; if the spec's maximum `pageSize` is higher than what we send, use what we send) and cap the response body read size (use `resp.read(MAX_BODY_BYTES + 1)` with `MAX_BODY_BYTES = 32 * 1024 * 1024` and raise PpdmError beyond it). Tests with fake responses. Document both constants in the module docstring.

**Q2.5 `config` and `id`** — `merge_config` (inventory_source, storage_system): also treat `id` (and `_links`) as a colliding/forbidden key in `config` (fail with the key names), since the body id could differ from the path id on PUT. Tests.

**Q2.6 generator hardening** — `tools/generate.py`: reject Python keywords as module/option names (`keyword.iskeyword`) and soft keywords that are unsafe as parameter names; type-check every option `description` entry (list of strings or a string) and the top-level `description` (list of strings); each with a clear error naming file+key and `main` returns 2. Tests.

**Q2.7 info modules exact match** — `info_main` with `name`: after the server-side filter keep only items whose `name` equals the requested value exactly (same rule as `find_one`); document that `filter` is passed through unchanged. Tests.

Update the role test to pin (a) and (b) by parsing the YAML.
